2. **Cloudflare Pages** — https://dash.cloudflare.com  
   Pages → Create → Upload assets. Unlimited bandwidth free tier. Best for production.

3. **GitHub Pages** (this repo)  
   Settings → Pages → Source: Deploy from branch `main` / root.  
   URL will be: https://kaungu89.github.io/demimadro-pos/

4. **Tiiny.host** — https://tiiny.host  
   Upload the single HTML file. Quick public link.

5. **Vercel** — https://vercel.com/new  
   Import this repo or drag-drop the HTML. Free hobby tier.

## Features

- Inclusive commission model (customer pays = transaction amount)
- Airtel / MTN / Zamtel tiers + bills & airtime
- ZRA 4% turnover tax on commission only
- Zeiko Agents integration panel
- Receipts, reports, CSV export
